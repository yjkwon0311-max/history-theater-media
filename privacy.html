개인정보처리방침

최종 업데이트: 2026-09-28

본 개인정보처리방침은 채널 소유자 본인이 자신의 YouTube 및 Instagram 채널에 콘텐츠(동영상·이미지·캡션·댓글)를 자동으로 업로드·게시하기 위해 운영하는 개인용 콘텐츠 발행 도구("본 도구")에 적용됩니다. 본 도구는 역사 실화극장, 셰프의 레시피, 소름 돋는 세상 채널의 콘텐츠 발행에 사용됩니다.

1. 수집하는 정보

본 도구는 일반 이용자의 개인정보를 수집·저장·공유하지 않습니다. 본 도구는 오직 채널 소유자 본인의 계정에 대해서만 작동하며, 소유자가 Google 및 Meta(Instagram) 로그인을 통해 직접 부여한 접근 권한(OAuth 토큰)을 사용해 소유자 본인의 채널에 콘텐츠를 게시합니다.

2. 정보의 이용

OAuth 접근 권한은 다음 목적에만 사용됩니다.

  • 소유자 본인 YouTube 채널에 동영상 업로드 및 공개 설정, 첫 댓글 작성
  • 소유자 본인 Instagram 프로페셔널 계정에 릴스 게시 및 댓글 작성
  • 소유자 본인 채널의 조회수·구독자 등 성과 통계 조회

본 도구는 이 목적 외의 어떤 용도로도 데이터를 사용하지 않으며, 제3자에게 판매·양도·공유하지 않습니다.

3. Google 사용자 데이터

본 도구의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수합니다. YouTube API 사용에는 YouTube 서비스 약관 및 Google 개인정보처리방침이 적용됩니다.

4. 정보의 보관

OAuth 토큰은 소유자 본인의 로컬 환경 및 발행 자동화를 위한 비공개 저장소(GitHub Actions Secret)에만 보관되며, 외부에 노출되지 않습니다. 소유자는 언제든지 Google 계정 권한 페이지에서 본 도구의 접근 권한을 철회할 수 있습니다.
